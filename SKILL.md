# Context Window Compaction Summarizer

## Description
Recursive conversational context compaction summarizer pruning middle turns into semantic bridges to preserve LLM token limits.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery
